# SQL for Data Analysis: Advanced SQL Querying Techniques
## Course Overview
This repository contains project files for the course "SQL for Data Analysis: Advanced SQL Querying Techniques." The course is designed to enhance your SQL skills, focusing on advanced querying techniques that are essential for data analysis.

## Contents
SQL Scripts: A collection of SQL scripts is provided to create and manage the datasets necessary for the course exercises and final project, designed for use with MySQL.

## Final Project
For the final project, there are analysis of: player data, salaries, school details and schools.
